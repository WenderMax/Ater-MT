
# Página ATER em Mato Grosso

Este é um site informativo sobre o Programa de Assistência Técnica e Extensão Rural (ATER) no estado de Mato Grosso.

## 📌 Objetivo
Divulgar informações sobre o impacto do programa na agricultura familiar, povos tradicionais, produção sustentável e protagonismo social no campo.

## 🚀 Como usar
1. Abra o arquivo `index.html` em um navegador web.
2. Ou publique o projeto gratuitamente usando plataformas como:
   - [GitHub Pages](https://pages.github.com)
   - [Netlify](https://netlify.com)
   - [Vercel](https://vercel.com)
